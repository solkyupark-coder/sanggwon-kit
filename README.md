# 주변 상권 분석 키트 (2주차 Next.js 키트)

가운데(내 땅)를 정하고 반경을 고르면, 주변 상가를 업종별로 세어 지도와 막대로 보여 줍니다.
키가 없어도 신림동 1573-28 반경 500m 샘플(상가 848곳)로 바로 돌아갑니다.

## 처음 한 번

1. 이 폴더를 바탕화면에 풀어 둡니다.
2. Claude 데스크톱 앱 → Code 탭 → 폴더를 이 폴더(sanggwon-kit)로 고릅니다.
3. Code 탭에 이렇게 씁니다.
   > 이 앱 실행해 줘.
4. 크롬에서 `http://localhost:3000` 을 엽니다. 열자마자 샘플로 결과가 나오고, 지도를 누르면 그곳을 바로 분석합니다.

## API 키 (환경변수)

키는 화면에 넣지 않습니다. 서버 환경변수에 넣습니다.

| 이름 | 넣으면 되는 것 |
|---|---|
| `VWORLD_KEY` | VWorld 배경지도, 지번으로 가운데 찾기, 필지 읽기 |
| `DATA_GO_KR_KEY` | 샘플 대신 아무 곳이나 상가를 바로 조회 (소상공인시장진흥공단 상가(상권)정보, 일반 인증키 Decoding) |
| `VWORLD_DOMAIN` (선택) | VWorld 키 받을 때 적은 서비스 URL. 비우면 지금 주소 |

- 내 컴퓨터: `.env.example`을 `.env.local`로 복사하고 `=` 뒤에 붙여 넣습니다.
- 배포한 곳: Vercel 프로젝트 → Settings → Environment Variables 에 같은 이름으로 넣고 다시 배포합니다.

화면 위 "API 키" 칸에는 연결됨/없음만 보입니다. 키 값은 브라우저로 안 옵니다.
코드 파일이나 Code 탭 채팅에 키를 붙여 넣지 마세요.

## 붙여 볼 데이터 (`public/data`)

| 파일 | 내용 | 지도에 바로 찍히나 |
|---|---|---|
| `stores.json` | 1573-28 반경 500m 상가 848곳 | 예. lon/lat 있음 (키트가 이미 씀) |
| `permits.json` | 신림동 건축 허가 969건 (2023-10 이후) | 아니요. 지번 주소만 있어서 좌표로 바꾸는 단계가 필요 |
| `trades.json` | 신림동 땅 실거래 568건 (2024-11~2026-10) | 아니요. 지번 뒷자리가 가려져 있어 표·차트로 |

## 배포

Code 탭에 이렇게 씁니다.
> 이 폴더 Vercel에 올려 줘.

배포한 뒤 Vercel 환경변수에 키를 넣고 다시 배포합니다. VWorld를 쓰려면 받은 `https://….vercel.app` 주소를 VWorld 인증키 관리 화면의 서비스 URL에 추가합니다.

## 막히면

- 화면이 하얗거나 버튼이 안 먹으면: 크롬에서 F12 → Console 탭의 빨간 글씨를 복사해서 Code 탭에 붙여 넣으세요.

## 이 땅에 뭘 지을까 (탭)

1. 위쪽 탭에서 **이 땅에 뭘 지을까**를 누릅니다.
2. 지도에서 땅을 한 번 누릅니다. VWorld 키가 있으면 그 필지를 읽고, 없으면 신림동 1573-28 샘플로 보여 줍니다.
3. 읽는 것
   - 필지 경계: VWorld 연속지적도 `LP_PA_CBND_BUBUN`
   - 토지이용계획(토지이음에 나오는 지역·지구와 같은 국토부 자료): VWorld `getLandUseAttr`
   - 면적·지목·공시지가: VWorld `getLandCharacteristics`
   - 주변 건물 높이: VWorld `LT_C_SPBD` 지상 층수 × 3m
4. 용도지역의 건폐율·용적률(서울은 도시계획 조례, 서울 밖은 국토계획법 상한)로 **임대형 기숙사를 가장 크게 지은 매스**를 층마다 쌓아 3D로 보여 줍니다.
5. 거친 1차 검토입니다. 일조·도로 사선, 주차, 조경, 지구단위계획은 넣지 않았습니다. 표는 `lib/zoning.ts`에 있습니다.

Claude에게 시켜 볼 것: "정북 일조 사선을 넣어 줘", "층높이를 3.3m로 바꿔 줘", "주차 대수도 세어 줘".
